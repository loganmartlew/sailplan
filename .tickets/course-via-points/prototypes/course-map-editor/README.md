# Course Via Points prototypes

These are throwaway assets for the Course Via Points Wayfinder decisions, not
production app code.

Run from the repository root:

```sh
python3 -m http.server 8000
```

Open [the Course Map/editor prototype](index.html). It
has three layouts via `?variant=map`, `?variant=story`, and `?variant=segment`.
Use the scenario picker to exercise no Via Points, a headland detour, a
multi-point channel, and overlapping Legs. The floating control (or left/right
arrows while no text field is focused) changes variants.
