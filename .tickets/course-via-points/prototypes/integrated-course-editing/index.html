THROWAWAY PROTOTYPE. The integrated Course Detail → Course Map → Course Plan flow for ticket 07. There is no draft and no Save/Cancel — every action commits the instant it's unambiguous — so what's under comparison is how the Course Map relates to Course Detail and how each committed action gets reversed. The one deliberate exception: dropping or moving a map pin previews the position and waits for an explicit confirm, because a spatial tap can't be judged correct until you see it — every other action (rename, reorder, remove, promote, Change Mark) still commits on the one gesture that expresses it. Switch with the floating control or ←/→. State is in memory and shared across variants.
